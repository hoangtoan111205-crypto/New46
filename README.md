# CodeGym Career Landing Page - SASS refactor

## Files
- `index.html`: landing page HTML.
- `scss/style.scss`: SCSS source, includes SASS variables, nesting, and a reusable mixin.
- `css/style.css`: compiled CSS used by the browser.
- `script.js`: existing page interactions.

## Important
The HTML links to `css/style.css`. Browsers do not read SCSS directly, so keep the compiled CSS file in the repository too.

## GitHub mobile upload
1. Open your repository in a browser.
2. Tap **Add file** → **Upload files**.
3. Extract this ZIP on your phone first, then upload the files/folders while preserving the structure above. If GitHub mobile cannot upload a folder, create `scss/style.scss`, `css/style.css`, and `index.html` individually using **Add file** → **Create new file**.
4. Commit changes.
